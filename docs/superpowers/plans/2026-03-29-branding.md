# SHOOOT Branding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add brand identity — SVG logo, favicon, and instructional empty states.

**Architecture:** Three new components (Logo, EmptyPlayer) plus a favicon SVG. Logo replaces the text span in App.tsx header. EmptyPlayer conditionally renders when no files are loaded. GoalList gets an enhanced empty message.

**Tech Stack:** React, Tailwind CSS (v4 with Stadium Pink theme already configured), inline SVG.
